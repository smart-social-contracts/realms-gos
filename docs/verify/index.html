Verify a signed document

A realm's canister signs its documents (its official journal, and others) with a key the Internet Computer derives for that canister. This page checks the signature in your browser: nothing is sent anywhere except the request that fetches a proof, and no script is loaded from elsewhere.

      Is this key the canister's?
      
    The signature proves the text was signed by whoever holds the key in it. That the key is this canister's
        is something the Internet Computer settles: it derives the key from its master key, the canister id and the path
        shown above, and only that canister can ask for a signature under it. A page cannot get that from the canister
        (an answer to a query is not certified, and checking a certificate needs a library of its own), so derive the key
        yourself, offline, and paste it in "Expected public key" above:
