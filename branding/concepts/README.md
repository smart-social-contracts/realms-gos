# Realms GOS logo

The official Realms GOS mark is the **dotted planet** (issue #310).

| Asset | Use |
|-------|-----|
| Icon (planet only) | Favicon, app chrome, compact mark |
| Wide lockup (planet + “realms”) | Nav bars, headers, marketing |
| White variants | Dark backgrounds |

Canonical sources live in this repo’s deployed copies:

| Deployed filename | Asset |
|-------------------|-------|
| `logo_mark.svg`, `logo_sphere_only.svg`, `favicon.svg` | Icon (black) |
| `logo_mark_white.svg`, `logo_sphere_only_white.svg` | Icon (white) |
| `logo.svg`, `logo_horizontal.svg` | Wide lockup (black) |
| `logo_horizontal_white.svg` | Wide lockup (white) |

Paths: `src/*/static/images/`, `website/public/`, `docs/img/`, and CLI mirrors under `cli/realms/`.

The legacy filename `logo_sphere_only.svg` is kept for path compatibility; it now serves the same planet icon as `logo_mark.svg`.
